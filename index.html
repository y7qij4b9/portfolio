I'm Alexander, 17. I started writing code two years ago and fell into Minecraft server work about a year in. Since then I've been head developer of moonprac.net, built private plugins for server owners, and worked on a PvP client down to the internals.

Java and C++ are home. I've written Rust and C# on the side. I care about behavior under load: why a server stutters, why a client feels off, why a config that looks fine falls apart once players show up. I take things apart to answer those questions.
